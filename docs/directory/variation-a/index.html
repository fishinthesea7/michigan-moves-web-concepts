One community, three primary roles

Know what each role means

Every profile has one primary Coalition relationship. CEO Pledge Signer is a separate workplace commitment that can appear as an additional credential.

Coalition AmbassadorStays informed, shares resources, and advocates locally with no required meetings.
Coalition MemberParticipates in a sector committee and helps implement the Michigan Physical Activity Plan.
PartnerHas a formal organizational relationship established by mutual agreement.
